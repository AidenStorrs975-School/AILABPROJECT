# AILABPROJECT

## Blackjack

Open `index.html` in a modern browser to play. The game uses fictional play credits, keeps all state in the page, and needs no install or server. It uses the browser's cryptographically secure random-number generator to shuffle a fresh single deck for each round.

Controls: choose a bet in increments of 10 credits, then deal. During your turn, hit, stand, or double down. Blackjack pays 3:2; the dealer stands on soft 17.
